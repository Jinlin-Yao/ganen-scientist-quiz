- 感动中国：选收2021—2025年度的科研、工程、医学、农业技术、科普及科研求学人物；非科研仅保留苏炳添、郑钦文两位知名代表。2025年度于2026年公布。

## 维护与校验

编辑 `data/people.json`，运行 `python scripts/build-people.py` 和 `node scripts/test-people.cjs`。题目 ID 由人物名和考点键生成，调整条目顺序不会清空作答记录。原题库的 `node scripts/test.cjs`、`node scripts/test-progress.cjs` 也须通过。

每个人物有逐条资料引用；新增网络资料保留官方链接。原始用户材料仅引用文档名与段落编号，不上传原始附件。对于材料中的任职、称号与事实，题库只按条目表述，不将所有人都称为院士或科研成果获得者。
